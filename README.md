# TomTom-NAV4-MSTMS-Map-Update-Guide
Step-by-step guide to root, free internal storage, and install updated maps &amp; speedcams on TomTom NAV4 devices using MSTMS and TTActivator. Tested on a TomTom GO 500 (Navcore 25.100); compatible with other NAV4 models (GO, Start, Via series) though untested on other hardware.
